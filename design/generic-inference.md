# 泛型调用推断设计

## 概述

泛型推断与显式泛型参数赋值共存。省略 `[...]` 时相当于没有任何从外部传入的泛型参数，全部需要推断；部分传入时，未传入的参数由推断补全。

## 流水线

```
泛型函数调用 → 传入泛型参数表（可空）→ 推断（形式化校验）→ extends 约束 → 生成实例化函数 → 调用
```

1. **传入泛型参数表**：显式传入的泛型参数先赋值到泛型参数作用域，未传入的保持占位符
2. **推断（形式化校验）**：通过实参类型反推占位符的值，同时做形式化校验
3. **extends 约束**：推断完成后，检查所有泛型参数是否满足 extends 约束
4. **生成实例化函数**：调用 create_fn_instance 生成具体实例
5. **调用**：执行实例函数

## 推断流程

### 1. 初始化占位符

为每个泛型参数创建占位符 value：

- **类型占位符**：特殊 type（`TYPE_KIND_GENERIC_PARAM`），`data` 指向自身名字（如 `"T"`）。参与临时类型构造（如 `[]T`）时不报错，同时记录名字供后续赋值插入 scope。
- **值占位符**：`data=NULL`，仅用于数组长度等值参数场景，表示"未知值"。
- **参数包占位符**：特殊 type（`TYPE_KIND_GENERIC_PACK`），在同一位置吸收所有后续类型。例如声明 `<i32, ...T>` 视作 `<i32, pack>`，输入 `<i32, i32, i64, i8>` 时后三个全部吸收进 pack。

### 2. 构造临时类型

用占位符构造临时类型，与实参类型递归比较：

- `[]T` → `slice_type(pointee=占位T)`
- `[N]T` → `array_type(count=值占位N, elem=占位T)`
- `func(T, T) -> T` → `callable_type(param_types=[占位T, 占位T], return_type=占位T)`

### 3. 遍历参数，递归匹配

逐对比较 AST 声明的形式类型（左值/临时类型）和实参类型（右值）：

1. **形式验证**：先检查结构形式是否匹配（如 slice vs array → 报错）
2. **递归解析**：形式相同则递归到子类型/子元素
3. **赋值时机**：递归到左值为占位符时，clone 右值到泛型参数作用域，名字从占位符获取
4. **一次性约束**：同一泛型参数首次推断时赋值，后续出现必须精确匹配已赋值类型，不兼容则报错
5. **无 safe_cast**：推断过程中不做 safe_cast，要求精确匹配

### 4. 参数包特殊处理

参数包参与的类型无法使用"构造临时类型 + extends 校验"的方式，因为参数包大小不确定，无法构造完整的 callable_type_t 或 tuple_type_t。

参数包场景：
- **顶层参数列表**：最简单，`...T` 吸收剩余实参，逐个推断
- **tuple 中**：如 `(T, ...T)` 需要特殊处理展开
- **callable 中**：如 `func(...T)` 需要特殊处理展开

### 5. 推断完成检查

遍历完所有调用参数后，检查泛型参数作用域中是否仍有未推断的占位符（`data=NULL` 或 `data` 指向 `TYPE_KIND_GENERIC_PARAM`），有则报错。

## 示例

```
func fib[T](n: T): T { ... }
fib(7)  // T 推断为 i32 → 等价于 fib[i32](7)

func add[T](a: T, b: T): T { ... }
add(1, 2)    // T = i32 ✓
add(1, "hi") // T 第二次出现期望 i32，实参是 str → 报错

type Array[N]T = [N]T
Array[3](1, 2, 3)  // N=3, T=i32
```
